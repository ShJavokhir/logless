# Video brief — contract

A one-minute, highly visual video summary of the **published map**. It is generated by a director agent on GLM 5.3
(Vultr Serverless Inference) and played in the browser by a Remotion composition (`web/src/video/`).

The division of labour mirrors PRDs (`backend/logless/api/prds.py`):

- **GLM directs; code supplies every number.** GLM sees only the published snapshot as a compact *facts sheet*
  (the same aggregates the map shows, no rows, no text from conversations beyond the published cluster
  titles/descriptions/needs/problems). It returns a storyboard: which scenes, in what order, how long, and the
  words on screen. It may not write digits, `%` or number words. It may use `{placeholders}` from a fixed allowlist;
  the backend fills them from published metrics.
- **The gate.** Plain code validates the storyboard (scene types, order, durations, ids, placeholders, text
  lengths, no digits / number words, leak checks). On failure GLM gets **one** repair round, fed the validator's
  fixed-vocabulary problem strings (never data). Still failing → the run fails and nothing is shown.
- **Data for every scene is attached by code** from the snapshot, never by the model.

## Storyboard the model returns (`_BriefOut`)

```json
{
  "title": "What 5,350 people asked the assistant",           // NO digits; placeholders allowed
  "scenes": [
    {"type": "intro",      "seconds": 6, "headline": "...", "kicker": "..."},
    {"type": "map",        "seconds": 8, "headline": "..."},
    {"type": "top_workflows", "seconds": 7, "headline": "..."},
    {"type": "friction",   "seconds": 8, "headline": "..."},
    {"type": "signals",    "seconds": 6, "headline": "..."},
    {"type": "spotlight",  "seconds": 9, "headline": "...", "cluster_id": "cl_xxxxxx", "insight": "..."},
    {"type": "languages",  "seconds": 5, "headline": "..."},
    {"type": "takeaways",  "seconds": 8, "headline": "...", "bullets": ["...", "...", "..."]},
    {"type": "outro",      "seconds": 4, "headline": "..."}
  ]
}
```

Rules enforced by the gate:

- 6–10 scenes; first is `intro`, last is `outro`; `takeaways` appears exactly once, right before `outro`.
- Each type at most once except `spotlight` (1–2 times, distinct `cluster_id`s, each a *rankable* leaf — see
  `prds.rankable`). `map`, `friction` are required.
- `seconds`: integer 3–12 per scene; total 50–62.
- `headline`: 2–10 words. `kicker` (intro only, optional): ≤ 12 words. `insight` (spotlight): ≤ 30 words.
  `bullets` (takeaways): exactly 3, each ≤ 14 words. `title`: 3–10 words.
- No digits, `%`, or number words (zero…twenty, dozen, hundred, thousand, million, billion, half, twice, double,
  triple, quarter, third, percent, majority, most, minority) outside placeholders. Braces only for placeholders.
- Placeholders allowed everywhere: `{conversations}`, `{people}`, `{languages}`, `{friction_share}`,
  `{top_workflow}` (short title of the largest workflow), `{top_workflow_share}`, `{hotspot}` (short title of the
  workflow with the most friction conversations), `{hotspot_friction_share}`.
  In a spotlight scene additionally: `{share}`, `{friction_share_here}`, `{conversations_here}`, `{people_here}`.
- Same privacy checks as PRDs (no medical conditions, places, ages; `leakcheck.problems` on the filled text).

## API

- `GET /api/brief?snapshot_id=` → `{"status": "ready", "brief": …}` for the latest brief of that (default: current)
  snapshot, else `{"status": "none"}`.
- `POST /api/brief` body `{"snapshot_id"?: str, "regenerate"?: bool}` → cached and not regenerate →
  `{"status": "ready", "brief"}`; else starts a `kind: "brief"` run → `{"status": "pending", "run_id"}` (poll
  `GET /api/runs/{id}`; on `completed`, `GET /api/brief` returns the new one). In-flight de-duplication per snapshot,
  capacity + spend like PRDs. Run stages: `reading` (facts sheet from the published map), `directing` (GLM
  storyboard), `checking` (gate), with one repair round re-inserting `directing`, `checking`.
- Briefs are stored in `public.db` table `briefs(brief_id PK, snapshot_id, json, created_at)`; latest wins.
